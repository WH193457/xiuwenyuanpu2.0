# 绣纹元谱

绣纹元谱面向侗绣纹样整理、知识检索、智能解构、语义创作、文创贴图与三维展示。本目录用于 GitHub 源码上传，包含应用源码、80 件母纹、15 个纹样元、标注数据、必要页面素材和依赖版本记录。

## 启动网页

使用 Node.js 22.12 或更高版本，在本目录打开终端并执行以下命令。

```powershell
cd app/website
npm.cmd ci
Copy-Item -LiteralPath .env.example -Destination .env
npm.cmd run dev -- --host 127.0.0.1
```

按终端显示的本机地址访问。生产构建使用 `npm.cmd run build`。资源同步脚本会从规范标注数据生成网页所需的 JSON 与 WebP 文件。前端所需的数据和图片已经包含在源码目录中。

## 配置本机模型

完整 AI 功能需要配置本机 Python、GPU 推理环境与模型文件。SAM3 使用 `app/SAM3_SETUP.md` 中的配置方式。生成服务需要 SD1.5、侗绣 LoRA、Canny ControlNet 及本机语言、视觉模型，配置变量和模型版本见 `app/README.md`，已安装环境的版本清单保存在 `dependency-records/`。

本次上传内容已排除模型权重、打包运行环境、安装依赖、运行记录、TouchDesigner 二进制工程及网页构建成品。模型和工程文件应在分别检查后通过适合大文件的渠道提供。现有交接文档中的实验产物链接和部分启动脚本依赖完整开发环境，首次展示请使用上面的网页启动命令。

## 隐私处理

上传副本中的标志图片已清理作者、品牌和账号关联的隐藏元数据。检查脚本中的实名用户路径已替换为通用用户目录规则。根目录的 `.gitignore` 已覆盖本机配置、凭据、模型缓存、依赖、运行记录及编辑器配置，环境示例中的密钥字段为空。

`VITE_WLT_API_KEY` 应保持为空。现有 World Labs 接入通过前端读取该配置，真实服务密钥需要通过服务端保管后再接入。当前 `.env.example` 使用本机 API 地址，网页运行时可按本机服务端口配置。

上传前可用 `git status --short` 检查提交清单。新增图片、配置、运行记录或模型文件后，应再次核对个人信息与文件元数据。此前制作的运行包及压缩包应单独复核。

## 数据与资源来源

80 件母纹、15 个纹样元和 7 条资料来源记录保存在规范标注数据中。资料原始作者、机构和引用链接已保留，见 `app/website/src/data/sources.json` 及标注工作簿。第三方模型与工具出处见 `dependency-records/第三方资源说明.txt`。各项资源的使用与分发应遵循其对应许可。
