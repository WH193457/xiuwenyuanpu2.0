# 绣纹元谱网站

React 19、TypeScript与Vite构建的侗族纹样研究平台前端。完整项目说明位于上级目录`README.md`和`AGENTS.md`。

## 命令

```powershell
npm.cmd ci
npm.cmd run sync:data
npm.cmd run dev
npm.cmd run build
npm.cmd run preview
```

资源同步脚本默认读取上级目录的`纹样库/侗族/_标注成果`，生成`public/data`、`public/patterns`和`public/elements`。这些目录不是规范数据源，可以随时删除并重新生成。

## 页面

- `/`：流动纹谱首页。
- `/patterns`：80件纹样浏览与筛选。
- `/patterns/:id`：纹样详情。
- `/dynamic`：流动纹谱、参数调整与PNG画面导出。
- `/deconstruct`：本地SAM3智能解构。
- `/create`：知识推荐、语义画布、LoRA创生与迭代历史。真实生成需启动根目录的`scripts/start-lora.ps1`。
- `/workshop`：14款文创模型、类别筛选、曲面贴图编辑、视角控制和预览图下载。
- `/museum`：14款文创的三维展厅、分区浏览与展品近看。
- `/evaluate`：五维评价与浏览器本地记录。

前端环境变量参见`.env.example`。未启动SAM3服务时，除智能解构外的页面仍可使用。

## 创生操作

1. 选择母纹或纹样元，查看对应标注和资料来源。本机读图模型就绪后，可分析当前参考图或上传PNG、JPEG、WebP图片，网页接收上限为5MB。
2. 选择“保留母纹特征”“简洁文创”“连续纹样”或“综合探索”。知识推荐随目标、正向意图关键词和画布更新；展开“查看依据”可核对推荐路径与逐条原始标注。暂不需要的建议可隐藏，也可在“推荐对照设置”恢复或切换到旧方法。
3. 在六维语义画布中增删概念，将颜色、构图等条件关联到具体主体。“查看主体与条件层级”展示所属关系。停用主体会同时暂停其关联条件。
4. 填写中文创作意图，点击“用本机模型整理意图”。核对本机模型提出的英文条件，再点击“采纳并更新画布”。参考图分析也采用同样的确认步骤。创作方向和未采纳的中文意图只影响推荐，不会被直接作为生成提示词。
5. “补充描述（中文 / English）”可直接输入中文、英文或混合内容。预览或生成时自动在本机翻译中文，输入框保留原文，可展开“查看补充描述原文与译文”核对。纯英文直接使用；修改原文会使旧译文失效。预览还显示构图冲突、资料标记和条件采用／省略原因。新创作的侗绣风格强度为0.35，可调范围为0至1。
6. 生成候选并选择一张，逐项标记“已满足”“部分满足”或“未满足”。未核对项保持空白，各候选分别保存。若采用了可检测的全局结构条件，会显示图像像素参考指标；这些指标不是文化准确率或生成成功率。
7. 点击“根据核对结果调整下一轮”，以本轮保存的条件和当前候选种子为起点，提高待改进条件的优先级并更新推荐。预览后继续生成，在“轮次对照”检查变化。可保存批注、导出记录、下载图像，或进入文创贴图。

草稿及最近12轮结果保存在当前浏览器的IndexedDB中，刷新后可恢复。跨浏览器使用需另行保存生成图像和导出的创作记录。本机服务离线时页面显示连接状态和重试入口。

## 结构、配色与针线参考

创生工坊中启用“结构与配色参考”，选择母纹、纹样元或上传图片，调整裁切、主体提取、颜色和布局，点击“准备结构参考”。核对配色输入、轮廓和蒙版后，点击“采用此结构与配色”。更改设置会使准备状态过期，生成前需要重新准备并采用。参考轮廓应与画布主体匹配。

“参考材质”提供沿用参考纹理与针线材质引导，新编辑态默认选择针线材质引导。它在图生图前加入细线和布底条件。“增强针线质感”控制额外技法提示词。两项设置及准备图均随草稿、历史、恢复和JSON导出保存，旧草稿缺少材质字段时沿用参考纹理。结构参考默认关闭，开启后的重绘强度为0.55、轮廓强度0.8、图像尺寸512×512。

`node scripts/test-reference-conditioning.mjs`使用拦截API验证状态与兼容性。`node scripts/test-reference-conditioning-live.mjs --prepare-only`检查真实准备与预览，`--run-live-generation`还执行真实本机生成、历史恢复与导出。后两种模式需要网站与8001服务运行。

## 动态纹样与文创展示

流动纹谱提供针脚密度、起伏幅度、流光拖尾和原纹叠加调整。暂停保留当前画面，PNG下载保存画布原始分辨率。手机端优先显示预览。网页动画由Canvas绘制，TouchDesigner源工程可在页面下载后用TouchDesigner打开。

文创贴图提供14款产品：马克杯、陶瓷花器、随行保温杯、帆布袋、文化衫、织纹抱枕、丝巾、精装笔记本、装裱画、陶瓷杯垫、织纹书签、折扇、手机壳和拉链收纳包。产品目录由`productCatalog.ts`统一维护，可按器物、织物、案头、随身四类筛选。模型使用曲面网格、缝线与织物细节，印花通过UV映射沿表面变化。支持正面、背面、重置视角、自动旋转及预览图下载。

“物品配色”提供12种预设色和自定义颜色，主体与部件可分别设置，例如杯身与杯把、衣身与领袖边、包身与提带。部件的“自动”选项采用材质默认搭配。原纹图像保留自身颜色，产品底色填充图像透明区域及印花范围以外的表面。

在贴图调整中可修改大小、横纵位置、角度和连续重复。去浅色背景为可选操作，边缘连通浅色区域的处理结果用于当前产品材质。配色与排版提供各自的重置操作。切换文创采用该载体的默认排版，并保留当前主色和部件色，便于比较同套配色。保存方案和进入展厅会携带当前主色、部件色及排版参数，返回后可继续调整。展厅展示14款文创，当前选中的载体采用用户方案，其余采用各自默认排版与展陈配色，并提供分区与单件近看。

页面地址中的`pattern`与`carrier`优先于旧会话。`source=library`显示母纹原图，`source=session`使用对应母纹的已保存创作纹理。排版参数保存在URL和文创会话的`appearance`字段，早期无该字段的记录自动采用载体默认排版。`productColor`与`productDetailColor`支持六位十六进制颜色，保留旧版三种色名；部件色额外接受`auto`，旧方案缺少部件色时补为`auto`。创生结果交接与文创方案保存在当前标签页的`sessionStorage`中，失败时显示提示。旧记录中的自定义纹理保留，来源无法确认时显示“已保存纹理（旧记录）”。创作历史可从IndexedDB恢复并重新带入。

## 来源同步和回归检查

资料来源目录读取规范Excel中的“资料来源”工作表。工作表更新后，在website目录运行以下命令。

```powershell
python scripts/export-sources.py
npm.cmd run sync:data
```

同步时验证工作簿摘要、来源引用和原有80件母纹、15个纹样元。前端回归可通过以下命令执行，浏览器测试使用隔离的临时会话。

```powershell
node scripts/test-knowledge.mjs
node scripts/test-contextual-knowledge.mjs
node scripts/test-creation-history.mjs
node scripts/test-workshop-session.mjs
node scripts/test-product-materials.mjs
node scripts/test-dynamic.mjs
node scripts/test-workshop.mjs
node scripts/test-museum.mjs
node scripts/test-co-creation.mjs
node scripts/test-paper-workflow.mjs --vision
```

后两项需要网站与8001服务运行，会调用本机模型并保存真实生成输出。带`--vision`的检查还需要参考图模型安装完成。
